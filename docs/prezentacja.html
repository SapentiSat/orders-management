Po co to robimy

Wejście biznesowe

  • Bufor
  • Sprzedaż
  • Czas realizacji zamówienia (często 3–6 mies.)

Cel

  • Wiedzieć co i ile zamawiać
  • Uwzględnić MOQ, Order Increment, LT
  • Nie polegać na ABC/XYZ z ERP
  • Raz w tygodniu: Excel + mail + panel

Idea w jednym zdaniu

Pobieramy 2 pliki z FTP → liczymy sugestie i ABC/XYZ u nas → jeden Excel (jedna tabela) → chmura + mail → AI tylko podsumowuje gotowy raport.

2 pliki FTP→ Pandas / logika→ 1× Excel→ Chmura→ Mail + AI

Dane: 2 pliki na FTP

A — Produkty (snapshot)

  • id, sku, ean, nazwa
  • producent, grupa
  • aktywny, koniec życia
  • stan, rezerwacje, ilość min
  • MOQ, Order Increment, LT (dni)

B — Sprzedaż (~rok)

  • id
  • data
  • ilość szt.
  • wartość netto
  • koszt

Join po id. W Excelu końcowym SKU/EAN do pracy operacyjnej.

Schemat danych

Produkty ──id──► JOIN ──► Excel (1 tabela) Sprzedaż ─┘ │ ├─ wolny stan = stan − rezerwacje ├─ tempo sprzedaży / pokrycie dni ├─ sugerowana ilość (LT + bufor + MOQ + OI) ├─ ABC / XYZ (własne progi) └─ tryb: auto-ready | do weryfikacji | skip

Jedna tabela — nie dwa światy

Nie dzielimy na osobny „automat” i „słabe”. Jedna lista + tryb + filtry + kolory.

TrybKiedy
auto-ready Stabilna sprzedaż, komplet MOQ/OI/LT, sensowny ABC/XYZ (np. A/B + X)
do weryfikacji Mało historii, AZ, sezon, braki danych — człowiek decyduje
skip Nieaktywny / EOL / brak sensu zamówienia

Jak liczymy sugestię

okno = lead_time + bufor zapotrzebowanie = prognoza na okno × sezonowość − (stan − rezerwacje) sugerowana_ilość = zaokrąglij w górę do Order Increment i uwzględnij MOQ (gdy zamawiamy)

ABC/XYZ liczymy sami (progi w ustawieniach) — nie z ERP.

Excel + dostarczenie

Excel

  • Jeden plik, jedna tabela
  • SKU / EAN widoczne dla osoby końcowej
  • Formatowanie, ikony, kolory trybów
  • zamowienia_YYYY-MM-DD.xlsx

Kanały

  • Upload: Google Drive / OneDrive
  • Mail cotygodniowy (dzień + godzina)
  • Panel: podgląd, historia, ustawienia
  • AI: podsumowanie po raporcie + stats tygodnia vs poprz. miesiąc

Flow cotygodniowy

Harmonogram / „Uruchom teraz” │ ▼ Pobierz 2 pliki (SFTP/FTPS) │ ▼ Mapowanie + walidacja ──ERROR──► log + mail alert │ ▼ Pandas: join, ABC/XYZ, sugestie, tryby │ ▼ Excel → chmura → AI (opcjonalnie) → mail raportowy │ ▼ Panel + logi (WARN/ERROR, 14 dni)

Ustawienia — co konfigurujemy

  • Harmonogram + uruchom teraz
  • SFTP/FTPS: ścieżki 2 plików
  • Chmura + retencja
  • Odbiorcy maila raportowego
  • Odbiorca alertów (ops)
  • Dostęp do panelu
  • Mapowanie kolumn (trwałe)
  • Progi ABC/XYZ
  • Bufor / LT / reguły trybów
  • Podpięcie modelu AI (dowolny)
  • Testy: FTP, SMTP, chmura, AI

AI — świadomie ograniczone

  • Działa po wygenerowaniu raportu
  • Dostaje gotowe liczby — nie przelicza zamówień od zera
  • Zwraca: krótkie podsumowanie + ryzyka
  • Osobno: sprzedaż od daty w ustawieniach → dziś oraz porównanie z poprzednim miesiącem
